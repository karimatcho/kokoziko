# KOKOZIKO Creative Studio

A responsive one-page portfolio website for KOKOZIKO.

## Publish with GitHub Pages
1. Open the repository Settings.
2. Select Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the `main` branch and `/(root)`, then Save.
5. GitHub Pages will provide the published URL after deployment.

## Before sharing
- Review all copy and services.
- Replace the Freelancer contact link if you prefer another contact method.
- Add real portfolio work when ready. Do not present concept samples as client work.

Note: GitHub Pages hosting is free for public repositories. A GitHub Pages URL does not give you DNS control over github.io and does not, by itself, satisfy a DNS TXT ownership check for a different domain.
